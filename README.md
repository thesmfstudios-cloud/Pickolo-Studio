# Pickolo Studio MVP

Pickolo is an on-demand photography marketplace by SMF Studios.

## MVP scope
- Customer booking
- Partner workflow
- Admin control room
- Booking state machine
- Supabase foundation

## Local run
```bash
npm install
cp .env.example .env.local
npm run dev
```

## Next milestone
Supabase Auth → real booking API → payment-confirmed state → assignment engine → partner acceptance → completion/delivery → review/payout.
